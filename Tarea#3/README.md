# Tarea 3 Su primer TAD

La clase `Agenda` guarda contactos ordenados por nombre sobre una lista de Python.
Los nombres con mayúsculas o tildes diferentes son contactos distintos.
Para ejecutar las pruebas, desde esta carpeta use `python -m pytest -q`.
Para generar la medición use `python medicion.py`.
Las pruebas requieren instalar pytest una vez con `pip install pytest`.
